# 判据生成器（Criteria Generator）· 模板

> 不求 PDE 的"尺度标定路"，产出与任何实现无关的可证伪判据。
> 解完场后**逐条对照**；命中「若不满足」先怀疑实现缺陷，再怀疑物理。

## 1. 特征尺度表（先做，决定模型/网格/步长）

| 量 | 定义 | 数值 | 含义 / 结论 |
|---|---|---|---|
| 热扩散率 α | `k/(ρc_p)` | | |
| 扩散长度 l_T / l_C | `k/h`、`D/h_m` | | 膜阻 vs 内阻同量级？（网格须解析 l_C/10） |
| 毕渥数 Bi_h / Bi_m | `hR/k`、`h_mR/D` | | Bi≪0.1 才可集总；≈1 ⇒ 必须解 PDE |
| 渗透深度 | `2√(Dt)` | | 关注窗口内场有没有"穿透" |
| 瓶颈判据 | `D/(h_m·R)` | | <1 ⇒ 内扩散主导 |
| 时间尺度 | 过程积分（**非**单点 `R²/D`） | | 对齐题面自述量级（如"2–3 天"） |
| 刚性来源 | `∂lnD/∂lnC` vs `∂lnD/∂lnT` | | 决定精度敏感性 |
| 显式稳定限 | 热侧 `Δr²/(2α_max)` + 质侧 `Δr²/(2D_max)` | | 双满足，热侧常紧 ~16 倍 |

## 2. 判据句（每条：应满足什么 → 若不满足 → 先怀疑哪一个实现缺陷）

```
【判据 S-__】（应为 X 落在 [a, b]）
   若不满足 → ① 怀疑 …（如"把 g_w 当 g_d 用，差 ρ≈976 倍"）
              ② 怀疑 …（如"D 的 T 用了摄氏度"）
```

## 3. 自证局限（这条判据本身在哪个范围失效）

- 例：穿透理论判据仅在 `√(πDt) ≪ R`（t ≤ ~0.25 h）成立，之后只能当上限，不得作交付数字。
