# 数字溯源表（Provenance Ledger）· 模板

> 把"每个数字从哪来、可不可信"登记成表。只读复核 + 独立复算脚本 + 落文件行号。

## 判定五档

| 判定 | 含义 | 能否作交付数字 |
|---|---|---|
| ✅ 有据 | 可追题面/附件原文，或代码落盘（文件+键） | 能 |
| ✅ 推导值·有据 | 由有据数字算出，且经独立复算逐位核对 | 能 |
| ⚠️ 外部值未声明 | 题面未给、取了外部标准值但未声明 | 补声明 + 走上报 |
| ⚠️ 估算未标注 | 主观取数，未标「估算，非计算」 | 不能写论文 |
| ❌ 无来源 | 凭空出现、与自身公式不自洽 | 禁止下游引用 |

## 落地严重度 → 动作（P0–P3）

| 级 | 含义 | 动作 |
|---|---|---|
| **P0** | 凭空无来源数据 | **必须改数字** |
| **P1** | 外部值未声明 | 补声明 + 补灵敏度 |
| **P2** | 估算未标注 | 补标签（被下游引用则升 P0） |
| **P3** | 口径/引用错位（数字有据） | 只改表述 |

每条写：`文件 + 行 + 现状逐字原文 + 问题 + 建议改法 + 由谁改 + 由谁复核`；
**由谁改 ≠ 由谁复核**；先落盘正确值，再按落盘值改写文字（不许边改边猜）。

## 规则

1. **一个输入无来源 ⇒ 整条推导链判"无来源"**（分子错、分母口径未声明 ⇒ 比值整条作废）。
2. 复核是**只读**：只新建自己前缀文件，不修改既有文件；用自写脚本复算每个数字。
3. 顶部写**版本声明**：读入的是哪一版（行数/字节/时间戳）；判据文件被改写须声明并说明影响。
4. 修订/作废 → 下游引用**追溯作废**，写"修正版立此存照"。
5. 报告末尾单列**"勿改清单"**（确认无需修改的高质量处），防后续队伍误改对的地方。
6. **"数字修辞"重点怀疑**：整数倍数/百分比/取整量（"放大 100 倍"实 388、"24 倍"无法复现）必须给算式并复算。
