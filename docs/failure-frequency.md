## 五、结论（给 skill 排优先级用）

1. 最该防的不是"算错"，是**读错公式**——它前 4 位里带走了 3 个（D 读反、口径、数字修辞），且**盲测证明它是排版/提取的陷阱**，任何 agent 都可能掉进去。
2. **口径类错误**（体心/膜、干基/水质、平台/末值、挤水项）"单看不致命、合计是大头"，必须用**口径简报 + 显式声明 + 逐格 diff**三件套压住。
3. **"元错误"（编造/数字修辞/死参数/门禁自错/同源归并）单点致命、传播极快**，只能靠 §19–§22 的对账 + 审计 + 盲测兜底。
