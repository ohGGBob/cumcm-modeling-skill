# 量化失败台账（Failure Ledger）

> 用途：把 2026 CUMCM A 题工作区里 **每一类被验证过 "这样做会失败" 的做法** 登记成台账，每条含：症状 → 根因 → 便宜的抓法 → 后果量级 → 证据出处。
> 这是 `SKILL.md` 附录 A 的展开版，供审计子代理/复审时逐条对照。

## 一、读题区（公式/数据解读错误）

### F-1　PDF 分数指数读反（最高频、最致命）
- **症状**：Q1 表面水分 1.20（应为 1.51）、Q3 烘干时长 16.4 h（应为 ≈57 h）、Q4 19.6–21.3 h（应为 ≈50 h）。
- **根因**：附录 2/3/4 的 `D = A·e^(−k/C)`（C 在分母），纯文本提取 PDF 丢掉分数线，误读成 `e^(−k·C)`（C 在分子）。分子/分母只差一个符号，但物理行为反转：`e^(−k/C)` 随 C↓ 强烈衰减（干燥变慢），`e^(−k·C)` 随 C 几乎不变（扩散过快）。
- **抓法**：(a) PDF 公式区视觉读图；(b) 代码后 grep `exp(` 逐处核 `/` vs `*`；(c) 物理量级反推——指数型 D 随被除量下降必须衰减；(d) 独立子代理交叉（12 路正确族一致=16 倍于误读族）。
- **后果**：波及 Try1/Try4/图文详解/Try3-Q1 共 4+ 条管线，答案差 3.5 倍。
- **出处**：`AGENT_RESULTS_SUMMARY_20260913.md` §3、`agent_results_matrix.csv`、`工作区资料总汇总_A题.md` §4.1。

### F-2　温度单位用 ℃
- **症状**：`e^(−3850/T)` 量级错，长期干燥速率失真。
- **根因**：D 的 Arrhenius 因子 T 必须取 K。
- **抓法**：公式区视觉核验 + "温度一律 K" 口诀。
- **出处**：`report/data_inventory.md` §2.2（F-1 相关）。

### F-3　附件物理含义误判
- **症状**：把附件1 的"水分浓度 0.02–0.05"当药材含水率（药材初始 2.55），差两数量级。
- **根因**：只看到列名"水分浓度"就代入，未核对量级与物理角色（那是烘房空气湿度）。
- **抓法**：数据清单必须登记每个附件列的**物理含义 + 量级**；与题面初始条件对拍。
- **出处**：`report/data_inventory.md` §2.1、§2.3。

### F-4　附录参数串用
- **症状**：交出系统偏差结果。
- **根因**：附录2/3/4 的 ρ/cp/k/D 三组互不通用，代入错一组。
- **抓法**：口径文件明确"每问用哪组"，代码里注释断言参数组别。
- **出处**：`report/data_inventory.md` §2.2。

## 二、数值区（离散/装配/稳定性）

### F-5　显式格式 + 表面半单元 → NaN
- **症状**：约 356 s 后全场 NaN。
- **根因**：表面半单元热惯性极小，其显式稳定限 `Δt·A·h/(V_s·ρc_p) < 2`，与体扩散限 `Δr²/(2D)` 是**两个独立约束**；Δr=0.5 mm 时 Δt=1 s 已超限必发散。
- **抓法**：表面半单元 Δt 判据表（Δr=1 mm→Δt≤0.1 s 留 10 倍裕度）。
- **出处**：`report/FAILURE_MODES_verified.md` 失败案例 1。

### F-6　守恒变量线性化不自洽 → 均匀场崩
- **症状**：水分场在 Δt=0.01 s 也崩到 0（C_s: 2.55→9.1e-7），与步长、潜热无关。
- **根因**：`w=ρ(C)C` 下，储存项系数与通量项系数不是同一套 ρ；均匀场不是离散方程的精确解。
- **抓法**：**UT2 均匀场测试**——场≡初值解一次必须仍是初值（<1e-9），1 秒抓出。
- **出处**：`report/FAILURE_MODES_verified.md` 失败案例 5。

### F-7　`ρD` 强非线性一次性全隐式 → 一步打飞
- **症状**：C 一步从 2.55 崩到 0，表面 T 掉到 12.91 ℃。
- **根因**：离散算子与连续算子不等价，表面格体积-面通量配对不自洽，一步解到错误定常态。
- **抓法**：S1（环境≡初值场不动）+ 单元测试 + 半单元成套（体积不额外放大导度）。
- **出处**：`report/FAILURE_MODES_verified.md` 失败案例 2。

### F-8　极点单元面心≠体心 → 一阶退化
- **症状**：中心点收敛阶 ≈ −1.00，第 4 位小数不可信。
- **抓法**：`4α(T₁−T₀)/Δr²` 的 L'Hôpital 形式。
- **出处**：`HANDOVER.md` §三、`report/FAILURE_MODES_verified.md`。

### F-9　表面边界层未解析
- **症状**：Δr=0.1 mm 时最外单元平均变负。
- **抓法**：表面列声明口径（膜 vs 体心），网格在近壁加密或改用边界反解值。
- **出处**：`workbuddy/docs/06_cumcm2026A_工程评估.md` §七（"A_out=1.0 放大 7.958 倍"同属归一化 bug）。

### F-10　归一化忘记加尺度校正
- **症状**：`A_out=1.0` 使算子放大 7.958 倍。
- **抓法**：无量纲/归一化变换后必须做尺度回代与量纲自检。
- **出处**：`workbuddy/docs/06_cumcm2026A_工程评估.md` §七。

## 三、物理区（口径/物理解读分歧）

### F-11　漏乘 ρ_dry —— "假通过"的代表
- **症状**：把"潜热是主导项（18.9 倍）"算成"小项 2.3%"，且温度"恰好"落在合理区间——比真失败更像真通过。
- **根因**：传质方程用干基通量 `g_d=h_mΔC`，能量方程的潜热汇必须用真实水质通量 `g_w=ρ_dry·g_d`，差 ~822 倍。
- **抓法**：G-1——显式报 `q_lat=L_v·g_w`、确认 `g_w=ρ·g_d`、报比值及温度基准；"T_s 落在 [28,T_air]" 不构成通过证据。
- **出处**：`report/R2C_VERDICT_v2.md` §四 G-1、`report/LATENT_HEAT_PROVENANCE.md` 来源③⑤。

### F-12　把 C_s 钉死（锁死水分场）
- **症状**：R2-C 求得 T_s=−31.9 ℃，称"题面 h_m 与感热不自洽"。
- **根因**：把表面浓度硬钉在 2.55（未知量当已知量），导致能量平衡反解出的负温其实是**钉死导致的不自洽态**，不是题面不自洽。
- **抓法**：G-4 边界—场自洽（累计失水→Δ⟨C⟩_boundary vs Δ⟨C⟩_field，差 5×10⁸ 倍→一票否决）；正确串联解 C_s≈0.16，潜热 q_lat≈0.27 W/m²，无负温。
- **出处**：`report/R2C_VERDICT_v2.md` §2、§四 G-4。

### F-13　同一套交付物 Q3/Q4 口径不一致（唯一实质错误交付）
- **症状**：cumcm2026A 的 Q4 100 h 中心含水率仍 2.46，论文据此写"附录4 D 太小未达标"。
- **根因**：Q3 用 `D·∂C/∂r`、Q4 用 `ρD·∂C/∂r` 且容量取 `(ρC)'≈1189`，表面被锁死（附录4 D 只小 2–5 倍，非论文声称的 1400 倍）。
- **抓法**：同系统变体量级自洽核对；主代理跑通源码复现证实是 bug 而非物理结论。
- **出处**：`A题全工作区审理报告_v2.md` §4。

### F-14　题面未给的常数被自行取值（L_v 事件）
- **症状**：L_v=2.3e6 全程未声明"题面未给"、未上报，且不同的推导链给出互相矛盾的潜热数字。
- **抓法**：铁律 4——卡住上报；外部取值必须标注 + 灵敏度；最终用户拍板显式声明。
- **出处**：`report/DISCIPLINE_no_fabrication.md` 事故③、`LATENT_HEAT_PROVENANCE.md`。

## 四·补、求解器验收 / 仲裁 / 合规三条新坑

### F-19　单元测试通过与求解器错误并存（绕过关键项的假通过）
- **症状**：母会话自研求解器 UT1/UT2/UT4 全 PASS，第 2 问仍错（T_s 偏 +2.91 K、C_s 偏干 1.56 倍），网格加密不变。
- **根因**：UT2 用 `h_m=0` **绕过了表面通道**——测试只覆盖了"通量散度/追赶法"，没覆盖出事的那一项。网格加密不收敛 ⇒ 装配错而非收敛问题。
- **抓法**：金样本前置复现（先复现已验证的第 1 问交付值，偏差 >0.1 K/0.01 即停）+ 每个关键项配专属 UT（UT6 专打表面膜通道）。
- **出处**：`report/SOLVER_VERIFICATION_finding.md` §二/§四。

### F-20　"不可比比值"当证据、同源恒等式零信息（仲裁里的思维陷阱）
- **症状**：甲方用"820 倍失水"控告求解器；乙方用"比值随 Δt 变"控告；X3 逐条复测后**双方各自都犯过口径错**。
- **根因**：干基量 ÷ 体积量 = ρ_dry(=820)、瞬时 ÷ 累计 = 1/Δt、kg/m² ÷ kg/m = A_out——全是不可比比值；`ρh_mΔC/(h_mΔC)≡ρ` 是恒等式，对参数零敏感性、无鉴别力。
- **抓法**：证据审查五维（分子/分母/区间/口径/可比性）；判决性实验 = 独立自写求解器逐点复现交付表（A 偏差 0.0068 vs C 2.2268）。
- **出处**：`report/q2v3_ruling.md` §3、§4。

### F-21　合规红线漏项（匿名/页数/附录程序/AI 声明）
- **症状**：直到收口才发现正文含本地绝对路径（用户名）、AI 声明句式非官方、工具型号是占位符、参考文献为空。
- **根因**：合规被当"软任务"后置，匿名的机器路径、AI 声明的逐字句式、工具型号"不可编造"这些**取消资格级红线**没进硬清单。
- **抓法**：清单只收"违反即取消资格"项、逐条标状态；`pdfauthor={}` + 全文扫描路径/学校/队号；AI 工具名型号由参赛者填（代理不可代填）。
- **出处**：`report/comp_RULES_CHECKLIST.md`、`report/REMAINING_TASKS.md` §C/D。

### F-22　门禁判据本身是错的（判据误导"修好代码"）
- **症状**：项目级门禁"一步后最外层 T=28.8305 ℃"被多处复制成硬判据；实际任何正确实现的一步结果都是 28.3796（差 0.451 ℃，容差 0.01 的 45 倍），会误导正确队伍去"修"本来对的代码。
- **根因**：28.8305 来自"把最外层与内层解耦"的未声明近似；它自己的另一行"环境=初值时一步后 28.4148"直接自我否证（凸组合要求仍为 28.000）。
- **抓法**：任何判据过两条自检——①环境≡初值时解必须还是初值；②判据是否隐含未声明的简化。守恒审计不能替代退化判据。
- **出处**：`report/prov_reconciliation.md` §5.2。

### F-23　对账期间判据文件被改写（版本漂移）
- **症状**：来源复核队 16:23 读入的判据文件是 119 行，16:29 被另一队改写成 178 行，铁律 4 整条被替换——复核结论的"严重度"随之升级，但多数下游仍按旧版在引用。
- **根因**：多队并行时无文件版本锁定，判据文件被改写后旧引用未追溯作废。
- **抓法**：对账/裁决文件顶部写"版本声明"（读入版本的行数/字节/时间戳）；判据变更必须触发下游引用追溯作废（§10.4）。
- **出处**：`report/prov_reconciliation.md` §⚠增补。

### F-24　跳过量纲/尺度标定直接写代码（把显式步长、模型选型算错）
- **症状**：把"集总模型"套在 Bi≈1.4 的题上；显式步长只算质侧、没算热侧（真实热侧限 2.27 s，被写成"88 s 有 88 倍裕度"）；低 C 段表面薄层只用 3 格/边界层。
- **根因**：没先做 α/D、Bi、渗透深度、D/(h_mR)、刚性来源、l_T/l_C 这套尺度标定，模型选型与网格/步长凭直觉。
- **抓法**：先派一路"判据生成器"（不求解 PDE、只出特征尺度表 + 可证伪判据句）——见 SKILL §17。
- **出处**：`report/R2Y_SCALES.md`、`A题补充材料/第一问_手算自学手册.md` §3/§8。

## 五、方法论速查（哪个坑用哪条判据）

| 坑 | 首选判据 |
|---|---|
| 公式读反 | 视觉读图 + grep `/`·`*` + 物理量级反推 |
| 装配/线性化错 | UT2 均匀场（场≡初值仍是初值） |
| 量纲/几何错 | S2 制造解 `lap(r²)=4` |
| 边界稳定 | 表面半单元 Δt 上限 + 体扩散限 |
| 守恒/口径 | 相对残差 <1e-9 |
| 场"假通过" | G-4 边界—场自洽（Δ⟨C⟩ 对拍） |
| 通量漏乘密度 | G-1 显式报 g_w=ρ·g_d |
| 结果不物理 | 期望量级自检表越界即查 |
| 数字不可信 | 可靠度分级 + provenance ledger |
| 结论被推翻 | 追溯作废 + 修正版立此存照 |
| 单元测试通过但仍错 | 金样本前置复现 + 关键项专属 UT（打到位） |
| 双方证据打架 | 证据审查五维 + 独立求解器逐点复现（防不可比比值/同源恒等式） |
| 合规/匿名/AI 声明 | comp 硬门清单逐条 PASS + 全文扫描身份信息 |
| 模型选型/网格/步长全凭直觉 | 量纲+尺度标定先行（α/D、Bi、渗透深度、刚性来源、薄层） |
| 门禁判据本身是错的 | 判据自检：环境≡初值须仍为初值 + 是否隐含未声明简化 |
| 数字来源不清 | 对账五档判定 + 一个输入无来源则整链无来源 |
